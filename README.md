# Day One, Day Seven — a tiny game, one week apart

[![Day one, day seven on make.fun](https://make.fun/badge/post-tiktok-day-one-day-seven-20261123-0327.svg)](https://make.fun/bounty/post-tiktok-day-one-day-seven-20261123-0327)

This repository is the entry for the make.fun bounty
[Day one, day seven](https://make.fun/bounty/post-tiktok-day-one-day-seven-20261123-0327).

The entry is a short TikTok video about one tiny agent-built game at two
moments in its life: the day it was made, and the same game after a week of
daily updates. The camera never moves — same map, same start — so the only
story is how much more is going on in the second visit.

## What is in here

- `VIDEO.json` — the full TikTok address of the entry video.
- `main.ts` — the entry program (Node 22). It copies `VIDEO.json` into the
  output directory; the house reads the video itself from that address.
- `LICENSE` — the repository license, added by `makefun init`.

## The video

- Day one: one hut, one hero, a quiet field — the game as it shipped.
- Day seven: the identical opening moment after seven daily updates — more
  buildings, more characters, crops grown, a fountain, flags and life
  everywhere, closing on the newer build being played.
